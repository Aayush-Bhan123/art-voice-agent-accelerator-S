ℹ️ Why audio wasn’t working

If you used a client that builds the URL from the page’s host (e.g. ws://localhost:8080/), it never hit ART. ART’s Genesys endpoint is ws://localhost:8010/api/v1/genesys/stream. This page defaults to that URL so you get two-way audio (mic → ART → Realtime → bot audio back).
